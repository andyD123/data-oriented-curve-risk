bench_library: curve sensitivities for a seasoned book, single thread
build:   AVX2 + FMA intrinsics backend; GCC 13.3.0
book:    500,000 instruments (bonds, IBOR swaps, OIS swaps); 9,310,805 cashflows, 18.6 per instrument
outputs: 66 sensitivities per instrument (30 discount-curve nodes + 36 projection-curve nodes); 33,000,000 values, 264.0 MB

terms
  output            one sensitivity: one instrument against one curve node
  SCAN              reference method: scalar ladder, one instrument at a time
  GRP               grouped method: 8 instruments at a time, one per SIMD lane
  date table        discount and projection factors at each unique payment date, shared by all groups
  per curve update  work that is repeated every time the curves change
  time              wall clock, best of 1 run

result: cost of one curve update                       time     per output
  SCAN  replication + scalar ladder                452.95 ms     13.726 ns
  GRP   date-table refresh + kernel                 38.87 ms      1.178 ns
  GRP is 11.7x faster than SCAN per curve update

breakdown
  SCAN  replication of unit cashflows (1)          280.33 ms     30.108 ns per cashflow
  SCAN  scalar ladder                              172.62 ms      5.231 ns per output
  GRP   kernel, normal stores                      115.05 ms      3.486 ns per output
  GRP   kernel, streaming stores (2)                38.14 ms      1.156 ns per output   <- used in result
  (1) each cashflow is re-expressed as unit cashflows whose amounts depend on the curves, so it is redone per update
  (2) streaming (non-temporal) stores write the output straight to memory, bypassing the cache

accuracy
  GRP vs SCAN max difference 3.6e-15 (relative to each instrument's largest sensitivity)

setup (one-off, not repeated per curve update)
  first replication 557 ms (includes memory allocation); group layout 930 ms
  3,638 unique payment dates in the date table; 64,750 groups of 8
  lane occupancy 96.5% (share of SIMD lanes holding a real instrument)
  storage 273.5 MB padded vs 264.0 MB logical (+3.6% for empty lanes)

correctness gate: PASS (GRP agrees with SCAN to 1e-9 relative; every value finite)
