scenario_bench: wave scenarios priced from an LRU date cache, single thread
build:     compiler baseline instructions; GCC 13.3.0
book:      100,000 instruments (bonds and vanilla swaps); 3,540 distinct curve dates
scenarios: 132 (30 discount waves + 36 projection waves, up and down), padded to 136
outputs:   6,600,000 sensitivities (66 per instrument, per unit forward-rate shift)

terms
  column      136 scenario factors at one date (1,088 bytes)
  misses      column computations, both curves; the floor is 7,020, each column once
              (3,480 discount-curve dates + 3,540 projection-curve dates)
  orders      random = shuffled; sorted = type, start date, tenor;
              grouped = start date, type, tenor (prototype ordering)
  full table  every date's column computed up front (3.9 MB per curve)
  time        wall clock per curve update, best of 3 runs
